# CareerLens AI

An AI-powered career assistant that generates personalized interview plans and finds matching jobs/internships for candidates. It analyzes a user's resume or self-description against a target job posting, produces a structured interview report (technical & behavioral questions, skill gaps, and a day-wise prep plan), scrapes live job boards for relevant openings, and can draft and send cold emails — optionally attaching an ATS-safe resume.

## Features

- **AI Interview Reports** — Upload a resume or describe yourself, paste a job description, and get a match score, technical/behavioral interview questions, skill-gap analysis, and a day-wise preparation plan generated by Gemini.
- **Multi-Platform Job Search** — Live-scrapes matching jobs and internships from Naukri.com, LinkedIn, Wellfound, and Indeed, then scores/ranks them against your profile.
- **Cold Email Assistant** — Draft a personalized cold email to a founder/hiring manager, preview it, and send it (with an optional resume attachment) via SMTP or Ethereal.
- **ATS-Safe Resume Generation** — Builds a single-column, machine-parseable resume PDF tailored to a specific posting.
- **Auth** — Register/log in with JWT cookie-based sessions and a token blacklist for logout.

## Architecture

The project is a monorepo (loose, no workspace tooling) with two apps:

```
GenAI/
├── Backend/            # Express REST API
│   ├── server.js       # Entry point (listens on port 3000)
│   └── src/
│       ├── app.js              # Express app, middleware, route mounting
│       ├── db/                 # MongoDB (Mongoose) connection
│       ├── models/             # User, InterviewReport, blacklist
│       ├── routes/             # /api/auth, /api/report, /api/jobs
│       ├── controllers/        # Request handlers per route
│       ├── middleware/         # JWT auth, multer file upload
│       └── services/           # AI, scraping, PDF, email logic
└── Frontend/           # React + Vite SPA
    └── src/
        ├── main.jsx            # Entry point
        ├── App.jsx             # Providers + router
        ├── app.routes.jsx      # Client routing
        └── features/
            ├── auth/           # Login/Register + Auth context
            ├── ai/             # Interview report pages/hooks
            └── jobs/           # Matched jobs + cold email UI
```

### Backend flow

1. `server.js` loads env vars and starts `src/app.js` on port `3000`.
2. `app.js` enables CORS for `http://localhost:5173`, connects to MongoDB, and mounts three routers.
3. Protected routes use `authMiddleware`, which validates the JWT from the request cookie and checks the token blacklist.
4. File uploads go through `multer` (in-memory, max 3 MB).
5. Heavy work lives in `services/`:
   - `ai.service.js` — Gemini calls for interview reports.
   - `job.service.js` — candidate profile extraction, job scoring, cold-email generation.
   - `scraper.service.js` — Playwright/Cheerio scrapers for Naukri, LinkedIn, Wellfound, Indeed.
   - `browser.service.js` — Chromium bootstrap with Puppeteer fallback.
   - `atsResume.service.js` — builds and validates ATS-safe resume PDFs.
   - `pdf.service.js` — HTML → PDF rendering via Puppeteer.
   - `email.service.js` — Nodemailer transport (SMTP, Gmail, or Ethereal).

### Frontend flow

1. `main.jsx` mounts `App`, which provides `AuthProvider` and `InterviewProvider` contexts and renders the router.
2. `app.routes.jsx` defines routes: Login, Register, Home (`/`, protected), Interview (`/report/:interviewId`, protected), and Jobs (`/jobs`, protected).
3. Each feature has an `api` service (axios, base URL `http://localhost:3000`, credentials included), pages, and shared context/hooks.

## Getting Started

### Prerequisites

- Node.js (18+ recommended)
- MongoDB (local or Atlas)
- A Google Generative AI (Gemini) API key
- Playwright Chromium (optional — falls back to Puppeteer's Chrome)

### Installation

1. Install root dependency (axios is shared at the root `package.json`):

   ```bash
   npm install
   ```

2. Install backend dependencies and browsers:

   ```bash
   cd Backend
   npm install
   npm run install:browsers   # download Playwright chromium (optional)
   ```

3. Install frontend dependencies:

   ```bash
   cd ../Frontend
   npm install
   ```

### Environment variables

Create a `.env` file in `Backend/` (the root `.gitignore` already ignores `.env`):

```env
# MongoDB
MONGO_URI=mongodb://localhost:27017/careerlens

# Google Generative AI
GOOGLE_GENAI_API_KEY=your_gemini_api_key

# JWT
JWT=your_jwt_secret

# Optional email (SMTP or Gmail). If omitted, Ethereal test transport is used.
EMAIL_USER=your_email
EMAIL_PASS=your_app_password
EMAIL_SERVICE=gmail
# or generic SMTP:
# SMTP_HOST=smtp.example.com
# SMTP_USER=user
# SMTP_PASS=pass
# SMTP_PORT=587
# SMTP_SECURE=false
```

> **Note:** If `EMAIL_USER`/`EMAIL_PASS` (or `SMTP_*`) are not set, the email service falls back to Ethereal and returns a preview URL instead of actually delivering mail.

### Running

Start the backend (from `Backend/`):

```bash
npm run dev      # nodemon, or: npm start
```

Start the frontend (from `Frontend/`):

```bash
npm run dev      # Vite dev server on http://localhost:5173
```

Open http://localhost:5173, register an account, and you're ready to generate interview plans and search for jobs.

### Scripts

Backend (`Backend/package.json`):

- `npm start` — run `server.js`
- `npm run dev` — run `server.js` via nodemon
- `npm run install:browsers` — install Playwright chromium
- `postinstall` — auto-tries Playwright chromium install (ignored on failure)

Frontend (`Frontend/package.json`):

- `npm run dev` — Vite dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run preview` — preview the production build

## API Reference

### Auth — `/api/auth`

| Method | Path        | Auth | Description                          |
|--------|-------------|------|--------------------------------------|
| POST   | `/register` | No   | Register a new user                  |
| POST   | `/login`    | No   | Login (sets JWT cookie)              |
| GET    | `/logout`   | No   | Logout (blacklists the token)        |
| GET    | `/get-me`   | Yes  | Get the current logged-in user       |

### Reports — `/api/report`

| Method | Path                       | Auth | Description                                    |
|--------|----------------------------|------|------------------------------------------------|
| POST   | `/`                        | Yes  | Generate an interview report (multipart)       |
| GET    | `/`                        | Yes  | List the user's reports (summary only)         |
| GET    | `/:reportId`               | Yes  | Get one report (scoped to the user)            |
| POST   | `/resume-pdf/:reportId`    | Yes  | Generate/download the user's resume as a PDF   |

### Jobs — `/api/jobs`

| Method | Path             | Auth | Description                                        |
|--------|------------------|------|----------------------------------------------------|
| POST   | `/match`         | Yes  | Find matching jobs/internships (multipart)         |
| POST   | `/cold-email`    | Yes  | Generate a personalized cold email                 |
| POST   | `/send-email`    | Yes  | Send the cold email, optionally with a resume      |
| POST   | `/ats-resume`    | Yes  | Build/preview the ATS-safe resume PDF              |

## Notes & known limitations

- **Scrapers depend on live sites** — job boards change markup and rate-limit bots. The backend reports diagnostics (which platforms were blocked) rather than silently showing "no jobs."
- **Gemini availability** — job scoring and profile extraction fall back to deterministic keyword-overlap scoring when the model is unavailable.
- **Email** — without configured SMTP credentials, mail is sent through Ethereal (test only) and a preview URL is returned.
- **Dev CORS** — the backend only allows origin `http://localhost:5173`.
